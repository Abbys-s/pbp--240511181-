
# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript/TypeScript | C#, Java, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, aplikasi diakses melalui browser | Aplikasi berjalan pada sistem operasi komputer | Aplikasi berjalan pada sistem operasi perangkat mobile |
| Cara distribusi | Melalui URL dan server web | Installer atau toko aplikasi desktop | Google Play Store, Apple App Store, atau distribusi lain |
| Keunggulan | Mudah diakses melalui browser dan tidak selalu perlu instalasi | Dapat memanfaatkan sumber daya komputer dan fitur sistem operasi | Praktis, portabel, serta dapat menggunakan kamera dan GPS |
| Keterbatasan | Bergantung pada browser dan sering memerlukan internet | Instalasi dan kompatibilitas bergantung pada sistem operasi | Sumber daya dan ukuran layar terbatas serta perlu memperhatikan kompatibilitas perangkat |
| Contoh aplikasi | Gmail versi web, Google Docs versi web | Microsoft Word, Visual Studio Code | WhatsApp, Google Maps |

## 2. Analisis

Platform web cocok untuk aplikasi yang perlu diakses melalui browser dari berbagai perangkat. Platform desktop sesuai untuk aplikasi yang membutuhkan integrasi dengan sistem operasi komputer. Sementara itu, platform mobile cocok untuk aplikasi yang digunakan secara praktis saat bepergian dan membutuhkan fitur perangkat seperti kamera, GPS, atau notifikasi.

Pemilihan platform harus mempertimbangkan kebutuhan pengguna, fitur aplikasi, keamanan, biaya pengembangan, serta kemudahan pemeliharaan.
