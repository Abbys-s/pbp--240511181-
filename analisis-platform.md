
# Analisis Komparatif Platform

## Tabel Perbandingan Platform Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|:---|:---|:---|:---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, diakses melalui browser | Aplikasi berjalan pada sistem operasi komputer | Aplikasi berjalan pada sistem operasi perangkat mobile |
| Cara distribusi | Melalui URL dan server web | Installer atau toko aplikasi desktop | Google Play Store atau Apple App Store |
| Keunggulan | Mudah diakses melalui browser tanpa instalasi khusus | Dapat memanfaatkan sumber daya dan fitur komputer | Praktis, portabel, serta mendukung fitur kamera dan GPS |
| Keterbatasan | Bergantung pada browser dan koneksi jaringan untuk fitur tertentu | Instalasi dan kompatibilitas bergantung pada sistem operasi | Sumber daya perangkat dan ukuran layar terbatas |
| Contoh aplikasi | Gmail versi web, Google Docs versi web | Microsoft Word, Visual Studio Code | WhatsApp, Google Maps |
